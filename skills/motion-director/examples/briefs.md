# Motion Director — Example Briefs

## SaaS launch

```text
Create a 30-second launch video for an AI workflow product.
Audience: operations leaders.
Message: repetitive work becomes an automated system.
Need: one product UI moment and one proof metric.
Tone: precise, modern, not cyberpunk.
```

Likely direction: Kinetic hook → Isometric system → Data proof → clean Swiss end card.

## Textile manufacturer

```text
Create a 30-second B2B promotional film for a textile manufacturer.
Audience: European private-label buyers.
Message: design precision, manufacturing capability, dependable delivery.
Assets: product photography, factory footage, production statistics.
Tone: premium, industrial, credible.
```

Likely direction: Swiss opener → Blueprint construction/quality → Data proof → Cinematic 3D or restrained product hero.

## Technology history

```text
Create a 60-second motion story connecting an early communication technology to today's AI.
Ground key moments in real historical facts.
Avoid a generic timeline slideshow.
```

Likely direction: Retro Futurism as historical signal language → Terminal/Data bridge → Generative finale.

## Style showcase

```text
Render one fixed phrase and motif in 15 motion design languages.
Keep content constant so viewers compare design systems directly.
The point is motion design itself, not product use cases.
```

Use all 15 only because comparison is the narrative.
