# Motion Director — Sequence Patterns

## 1. Hook → Proof → Hero

Best for product launches.

- Hook: Kinetic / Brutalist
- Proof: Data / Terminal / Blueprint
- Hero: Cinematic 3D / Generative

Use one shared shape or word across all three.

## 2. Build → System → Result

Best for industrial, workflow and B2B explainers.

- Build: Blueprint
- System: Isometric
- Result: Swiss or Data

Keep the same object identity from drawing to system to outcome.

## 3. Human → Machine

Best for AI or creative-tool stories.

- Human idea: Sketch / Paper
- Computation: Terminal / HUD
- Output: Generative / 3D

The transition should show transformation, not a hard “before AI / after AI” cliché.

## 4. Retro → Future

Best for technology history.

- Retro Futurism
- Terminal/Data bridge
- HUD/Generative or 3D

Preserve a line, signal, number or circle across time periods.

## 5. One Style, Deeply

Often the strongest choice for <10 seconds.

Use one style and escalate technique density:
- establish grammar
- introduce variation
- execute one hero transformation
- clean hold

## 6. Comparison Reel

Use only when the concept is explicitly “same idea, multiple visual systems.”

Hold content constant. Change only:
- visual grammar
- motion engine
- timing personality
- material behavior

This prevents the reel from becoming a list of unrelated use cases.

## Rhythm architecture

Alternate at least one macro property between adjacent scenes:
- dense ↔ sparse
- dark ↔ light
- fast ↔ slow
- flat ↔ deep
- rigid ↔ organic
- analog ↔ digital

Do not alternate everything at once; one strong contrast is enough.
