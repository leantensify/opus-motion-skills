# Motion Director — Style Selection

Choose by narrative function and motion engine.

| Need | Strong choices | Why |
|---|---|---|
| Immediate verbal hook | Kinetic Typography, Brutalist Web | language/state change creates instant energy |
| Precision / editorial authority | Swiss / International | hierarchy and grid communicate control |
| Construction / engineering | Blueprint | the object is literally built and measured |
| Computation / developer story | Terminal | input and output create causality |
| Evidence / metrics | Data Visualization | change is encoded in marks and values |
| Systems / workflow / logistics | Isometric | modules make relationships spatial |
| Organic transformation | Liquid Morph | continuity comes from shared mass |
| Tactile / culture / fashion | Paper Cut / Collage | physical layers create human texture |
| Playful progress / retro game | Pixel Art | actions become game mechanics |
| Ideation / learning / human process | Hand-Drawn Sketch | visible drawing shows thinking |
| Technology nostalgia | Retro Futurism | signal behavior becomes the edit |
| Premium hero / scale | Cinematic 3D Type | camera and depth create spectacle |
| Intelligence / sensing | HUD / Sci-Fi | tracking and measurement visualize system awareness |
| Emergence / abstract finale | Generative Motion | simple agents self-organize into meaning |

## Pairings that naturally hand off

- Kinetic → Swiss: letter stem becomes grid rule
- Swiss → Brutalist: cursor/action breaks the poster into raw page state
- Brutalist → Blueprint: border becomes drafting frame
- Blueprint → Terminal: dimension numbers become terminal text
- Terminal → Data: ASCII bars become chart bars
- Data → Isometric: bars extrude into modules
- Isometric → Liquid: circular module melts
- Liquid → Paper: blob freezes into paper disc
- Paper → Pixel: collage quantizes into cells
- Pixel → Sketch: pixels scatter into graphite points
- Sketch → Retro: marker strokes become signal stripes
- Retro → 3D: CRT line becomes horizon
- 3D → HUD: ring becomes reticle
- HUD → Generative: grid points detach into particles

## Conflict warnings

Avoid combinations that duplicate the same job without contrast. For example, HUD + Terminal + Data can become overly technical if all three are used only to say “advanced technology.” Assign distinct narrative functions or remove one.
