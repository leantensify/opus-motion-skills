# Cinematic 3D Type — Prompt Examples

## Example 1

```text
Create a 12-second cinematic 3D title reveal. Establish a horizon and fog, raise extruded type, perform one controlled orbit, then resolve face-on with a light sweep.
```

## Example 2

```text
Build a 3D transition where the camera flies through the O in the title and emerges into the next scene. Preserve the O as the portal geometry.
```

## Example 3

```text
Create a premium launch hero with restrained dust, strong depth hierarchy and one meaningful camera move. Avoid constant orbiting.
```

## Reusable brief

```text
Create a [DURATION] Cinematic 3D Type motion scene.
Objective: [OBJECTIVE]
Content: [CONTENT]
Required moments: [MOMENTS]
Constraints: [FORMAT / BRAND / AUDIO]
Let camera + depth drive the animation.
Preserve one strong hero frame.
Avoid generic slideshow transitions.
Deliver direction, timeline, implementation, code and QA notes.
```
