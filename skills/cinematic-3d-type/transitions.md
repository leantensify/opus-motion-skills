# Cinematic 3D Type — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | O → HUD Reticle | Fly through circle and lock it as a tracked target. |
| 02 | Horizon → Retro CRT | Flatten 3D horizon into a signal line. |
| 03 | Dust → Generative | Increase sparse dust into a structured particle system. |
| 04 | Extrusion → Isometric | Reduce perspective and quantize geometry into modular blocks. |
| 05 | Light Sweep → Swiss Rule | Flatten the light band into a graphic line. |
| 06 | Dive → Liquid | Enter a reflective surface that becomes fluid. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
