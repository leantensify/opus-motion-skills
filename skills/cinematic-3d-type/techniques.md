# Cinematic 3D Type — Techniques

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Fog Rise | Reveal extruded letters from volumetric haze. |
| 02 | Orbit Reveal | Arc the camera around type to establish depth before facing front. |
| 03 | O Fly-Through | Use a letter counter as a physical portal for camera transition. |
| 04 | Depth Rack | Shift focus/attention between foreground and background letter layers. |
| 05 | Light Sweep | Move a narrow light across the face to expose material. |
| 06 | Dust Field | Use sparse depth particles to communicate scale, not decoration. |
| 07 | Letter Lift | Raise characters from a floor plane with heavy easing. |
| 08 | Ring Depth | Place a circular motif at multiple z positions for parallax. |
| 09 | Hero Face-On | Resolve the camera to a clean frontal title after dimensional exploration. |
| 10 | Dive Cut | Accelerate through geometry until it fills frame, hiding the next cut. |

## Combination rule
Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA
- Can the style be recognized with color removed?
- Is motion driven by the style's engine?
- Does at least one technique support the message directly?
