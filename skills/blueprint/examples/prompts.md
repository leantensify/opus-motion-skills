# Blueprint — Prompt Examples

## Example 1

```text
Create a 12-second blueprint motion explainer for a manufactured product. Construct the object from centerlines and outlines, add meaningful dimensions, then resolve to a clean final drawing.
```

## Example 2

```text
Turn this product feature into a technical drafting sequence with callouts, section lines and an exploded assembly. Avoid decorative fake measurements.
```

## Example 3

```text
Create a 7-second opener where the phrase is literally constructed and dimensioned like an engineering drawing.
```

## Brief template

```text
Create a [DURATION] Blueprint motion sequence.

Objective:
[WHAT THE VIEWER SHOULD UNDERSTAND OR FEEL]

Content:
[WORDS / DATA / PRODUCT / OBJECTS]

Required moments:
- [MOMENT 1]
- [MOMENT 2]

Constraints:
- [FORMAT / BRAND / SAFE AREA / AUDIO]
- Let construction drive the motion.
- Preserve a clear hero frame.
- Avoid generic fade/slide slideshow behavior.

Deliver:
1. motion direction
2. timeline
3. implementation plan
4. code
5. QA notes
```
