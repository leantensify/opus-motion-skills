# Blueprint — Transition Recipes

A transition should inherit something from the previous shot and hand something useful to the next one.

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Dimensions → Terminal | Turn measurement numbers into green command-line output. |
| 02 | Grid → Swiss | Remove drafting texture but preserve the same alignment system. |
| 03 | Hatch → Scanlines | Animate hatching until it becomes retro CRT striping. |
| 04 | Section → 3D | Extrude a technical section into dimensional geometry. |
| 05 | Center Point → Particle Seed | Use the measured origin as the emitter for a generative scene. |
| 06 | Drawing Border → Frame | Carry the drawing title block into a HUD or data UI. |

## Transition test

A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only "fade to the next scene", look for a stronger transformation.
