# Blueprint — Techniques

These are reusable building blocks, not mandatory effects. Pick the smallest set that makes the brief clearer.

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Compass Circle | Construct a circle from center point, radius line, and arc sweep. |
| 02 | Dimension Build | Reveal width/height/radius measurements with witness lines and arrows. |
| 03 | Stroke Construction | Draw letter or object outlines in multiple structural passes. |
| 04 | Coordinate Callout | Attach x/y or numbered annotations to moving features. |
| 05 | Hatch Fill | After outline approval, fill regions with diagonal engineering hatching. |
| 06 | Exploded Assembly | Separate components along measured axes, then reassemble. |
| 07 | Leader Note | Animate technical notes with leader lines to exact components. |
| 08 | Centerline Lock | Use crossing centerlines to establish alignment before the object appears. |
| 09 | Revision Stamp | Introduce REV / APPROVED / DWG labels as editorial beats. |
| 10 | Section Cut | Slice through a form and reveal an interior section view. |

## Combination rule

Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA

- Can the scene still be identified as Blueprint with the color removed?
- Is the motion driven by the style's engine rather than generic transforms?
- Does at least one technique directly support the message?
