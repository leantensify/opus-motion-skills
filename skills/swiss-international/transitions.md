# Swiss / International — Transition Recipes

A transition should inherit something from the previous shot and hand something useful to the next one.

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Rule → Border | Expand a grid rule into the next scene's frame/border. |
| 02 | Circle → Cursor Target | Turn the geometric disc into a clickable target or tracked object. |
| 03 | Columns → Bars | Transform grid modules into data bars while preserving x positions. |
| 04 | Poster → Blueprint | Invert palette and retain grid/rules as drafting guides. |
| 05 | Block → Isometric Tile | Skew a rectangular module into an isometric plane. |
| 06 | Crop → Wipe | Use a full-height column to wipe to the next style. |

## Transition test

A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only "fade to the next scene", look for a stronger transformation.
