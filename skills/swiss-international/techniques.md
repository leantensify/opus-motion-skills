# Swiss / International — Techniques

These are reusable building blocks, not mandatory effects. Pick the smallest set that makes the brief clearer.

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Grid Draw | Reveal a 6/12-column grid briefly to establish logic, then let content inherit it. |
| 02 | Rule Snap | Animate a thin rule into an exact column boundary and use it as a transition anchor. |
| 03 | Module Flip | Rotate or swap rectangular modules while retaining grid coordinates. |
| 04 | Circle Drop | Introduce a primary geometric disc with gravity-like drop and precise stop. |
| 05 | Asymmetric Stack | Build a deliberately uneven type/image stack aligned to shared column edges. |
| 06 | Quarter Rotation | Rotate a block 90° around a grid intersection to reframe hierarchy. |
| 07 | Column Slide | Move content exactly one or more columns rather than freeform drifting. |
| 08 | Poster Build | Assemble title, index, date, rule, and shape as if laying out a poster in real time. |
| 09 | Crop Discipline | Use frame edges as active crop lines; animate objects through them without breaking alignment. |
| 10 | Counterpoint Motion | Move one small element against one large static field to create tension with minimal motion. |

## Combination rule

Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA

- Can the scene still be identified as Swiss / International with the color removed?
- Is the motion driven by the style's engine rather than generic transforms?
- Does at least one technique directly support the message?
