# Swiss / International — Prompt Examples

## Example 1

```text
Design a 10-second Swiss-style motion opener for a design SaaS. Use a 12-column grid, one accent circle, strict Helvetica-like hierarchy, and grid-driven transitions.
```

## Example 2

```text
Create a precise B2B product explainer section. Let modules reflow on the grid rather than using floating cards or generic fades.
```

## Example 3

```text
Turn these three metrics into an International Style motion poster with asymmetry, clear labels, geometric punctuation and exact alignment.
```
