# Kinetic Typography — Prompt Examples

## Example 1

```text
Create an 8-second launch hook for an AI product. Phrase: “BUILD LESS. SHIP MORE.” Make typography itself drive every transition. Use overscale slams, tracking changes and a counter morph. No decorative particle effects.
```

## Example 2

```text
Create a 12-second kinetic-typography title sequence for “THE NEXT INTERFACE”. Start minimal, escalate into repeated type rows, then resolve to one clean hero lockup.
```

## Example 3

```text
Turn this quote into a typographic motion piece. Animate only the most important words; keep the sentence readable and use semantic emphasis rather than random letter animation.
```
