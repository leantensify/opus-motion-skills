# Hand-Drawn Sketch — Timing

| # | Pattern | Guidance |
| --- | --- | --- |
| 01 | Stroke draw | 0.3–1.2s depending on complexity; line speed should feel hand-executable. |
| 02 | Boil | 2–4 variants held 2–4 frames each. |
| 03 | Note annotation | Write only short labels; 0.4–0.8s each. |
| 04 | Ink commit | Save the cleanest final state for the payoff. |

## General rules
Establish the system before escalating it. Let one major event dominate each beat. Hold important copy after motion settles. Review once with audio muted.
