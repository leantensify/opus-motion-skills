# Hand-Drawn Sketch — Shot & Transition Recipes

## 01 · Concept explanation

Construction lines → main object → labels/arrows → one corrected/redrawn feature → clean takeaway.

## 02 · Idea-to-product

Rough sketch builds; final contour gains confidence; then stroke straightens into polished UI or 3D geometry.

## 03 · Educational diagram

Draw one component at a time and annotate immediately, preventing dense final-frame overload.

## 04 · Sketch-to-retro

A broad marker stroke expands into horizontal sunset/CRT stripes.

## 05 · Humanized AI

Show prompt/idea as handwritten note; arrows connect to rough generated concepts; final idea circles itself.

## 06 · End card

Retain a few guide marks but simplify to one hand-lettered statement and underline.

## Handoff rule

Prefer transforming an existing material, edge, object, grid, line or texture into the first meaningful element of the next scene.
