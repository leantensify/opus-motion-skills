# Hand-Drawn Sketch — Prompt Examples

## Example 1

```text
Create a 12-second hand-drawn explainer where an idea starts as construction lines, gains annotations, gets corrected once, and resolves to a confident final sketch.
```

## Example 2

```text
Animate this concept like a designer's notebook: graphite guides, ink pass, margin notes and controlled line boil. Avoid random noisy wobble.
```

## Example 3

```text
Transition from a sketch into retro futurism by turning a broad marker stroke into horizontal CRT/sunset stripes.
```

## Reusable brief

```text
Create a [DURATION] Hand-Drawn Sketch motion scene.
Objective: [OBJECTIVE]
Content: [CONTENT]
Required moments: [MOMENTS]
Constraints: [FORMAT / BRAND / AUDIO]
Let strokes drive the animation.
Preserve one strong hero frame.
Avoid generic slideshow transitions.
Deliver direction, timeline, implementation, code and QA notes.
```
