# Hand-Drawn Sketch — Techniques

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Construction Pass | Show light guide geometry before confident final strokes. |
| 02 | Three-Pass Circle | Redraw the circle 2–3 times with slight variation. |
| 03 | Line Boil | Cycle between hand-offset versions of the same stroke. |
| 04 | Onion Skin | Show faint previous/next positions around a moving object. |
| 05 | Scribble Fill | Rapidly hatch or scribble inside a closed region. |
| 06 | Margin Note | Add arrows, handwritten labels, and underlines around the main drawing. |
| 07 | Erase Reveal | Remove graphite to expose clean space or a new idea. |
| 08 | Marker Sweep | Use thick felt-tip strokes as a scene wipe. |
| 09 | Sketch Bounce | Animate motion with visible key poses and hand-drawn arcs. |
| 10 | Ink Commit | Transition uncertain pencil construction into a crisp inked final form. |

## Combination rule
Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA
- Can the style be recognized with color removed?
- Is motion driven by the style's engine?
- Does at least one technique support the message directly?
