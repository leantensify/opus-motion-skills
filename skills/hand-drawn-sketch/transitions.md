# Hand-Drawn Sketch — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Marker → Retro Stripes | Extend marker bands into sunset/CRT stripes. |
| 02 | Pencil Dots → Pixels | Quantize graphite grain into square pixels. |
| 03 | Ink Line → Data Line | Clean a sketch stroke into a precise chart path. |
| 04 | Construction → Blueprint | Straighten hand guides into technical drafting geometry. |
| 05 | Scribble → Particles | Break hatch marks into generative strokes/points. |
| 06 | Page → Paper Collage | Introduce torn edges, tape, and physical layers. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
