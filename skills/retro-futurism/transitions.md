# Retro Futurism — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Power-Off → 3D Horizon | Keep the horizontal line and expand it into a dimensional horizon. |
| 02 | Sun Stripes → Sketch Marker | Translate bands into hand-drawn marker strokes. |
| 03 | Tracking → Brutalist Cut | Use VHS glitch as a hard scene switch. |
| 04 | Orbit → HUD Radar | Refine orbit paths into tracked sci-fi radar arcs. |
| 05 | Chrome → Liquid | Melt reflective letterforms into metallic fluid. |
| 06 | Scanlines → Blueprint Hatch | Freeze horizontal signal lines into drafting hatching. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
