# Retro Futurism — Prompt Examples

## Example 1

```text
Create a 10-second retro-futurist technology-history scene with CRT power-on, a striped sun, period-aware type and one motivated VHS tracking glitch.
```

## Example 2

```text
Build a retro launch title where a tape PLAY key triggers the composition and a tape counter paces three beats.
```

## Example 3

```text
Transition from CRT retro futurism into cinematic 3D by collapsing the screen to a horizontal line that becomes the 3D horizon.
```

## Reusable brief

```text
Create a [DURATION] Retro Futurism motion scene.
Objective: [OBJECTIVE]
Content: [CONTENT]
Required moments: [MOMENTS]
Constraints: [FORMAT / BRAND / AUDIO]
Let scanlines + signal drive the animation.
Preserve one strong hero frame.
Avoid generic slideshow transitions.
Deliver direction, timeline, implementation, code and QA notes.
```
