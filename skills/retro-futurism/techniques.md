# Retro Futurism — Techniques

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | CRT Power-On | Collapse/expand from a horizontal line with brief bloom. |
| 02 | Striped Sun | Build a segmented circular sun from horizontal bands. |
| 03 | Chrome Title | Reveal italic/extruded type with a traveling specular sweep. |
| 04 | Tape Counter | Animate mechanical digits as a secondary time motif. |
| 05 | Tracking Tear | Displace horizontal slices briefly as VHS tracking error. |
| 06 | RGB Split | Offset color channels only during transitions or impacts. |
| 07 | Scanline Sweep | Move a brighter scan band vertically through the frame. |
| 08 | Orbit Diagram | Animate thin elliptical orbits and small satellite points. |
| 09 | Tape Key | Use a physical-looking ▶ key with LED state. |
| 10 | Power-Off | Compress scene to line, then dot, then black. |

## Combination rule
Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA
- Can the style be recognized with color removed?
- Is motion driven by the style's engine?
- Does at least one technique support the message directly?
