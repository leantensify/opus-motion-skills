# Generative Motion — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Particles → Type | Settle targets into readable typography. |
| 02 | Particles → Pixels | Quantize positions to a pixel grid. |
| 03 | Particles → Data | Snap points to chart coordinates. |
| 04 | Grid → Flow | Release HUD/grid intersections into vector motion. |
| 05 | Collapse → Dot | End at one point that can seed another style. |
| 06 | Trail → Liquid | Thicken particle trails until they behave like continuous fluid. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
