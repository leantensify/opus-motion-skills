# Generative Motion — Techniques

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Flow Field | Advect particles through a deterministic vector field. |
| 02 | Text Assembly | Sample text pixels/paths as targets and attract particles into the phrase. |
| 03 | Ring Formation | Reassign the same particles from text targets to circular coordinates. |
| 04 | Explode/Reform | Release particles with velocity, then pull them into a new semantic target. |
| 05 | Noise Drift | Use seeded noise for organic movement between structured states. |
| 06 | Attractor Pull | Use one or more moving attractors to bend the particle field. |
| 07 | Trail System | Render fading positional history to expose motion structure. |
| 08 | Density Wave | Change local particle concentration as a compositional rhythm. |
| 09 | Target Morph | Interpolate correspondence between sampled shapes without random respawn. |
| 10 | Singularity Collapse | Pull all particles toward one point for a clean scene ending. |

## Combination rule
Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA
- Can the style be recognized with color removed?
- Is motion driven by the style's engine?
- Does at least one technique support the message directly?
