# Generative Motion — Prompt Examples

## Example 1

```text
Create a deterministic generative finale with 3,000 particles. Flow field → phrase → ring → play icon → final phrase → collapse. Use seeded randomness.
```

## Example 2

```text
Build a particle identity loop where the logo disperses through a flow field and returns to the exact initial state.
```

## Example 3

```text
Transition from a HUD grid to generative motion by using the actual grid intersections as particle seeds.
```

## Reusable brief

```text
Create a [DURATION] Generative Motion motion scene.
Objective: [OBJECTIVE]
Content: [CONTENT]
Required moments: [MOMENTS]
Constraints: [FORMAT / BRAND / AUDIO]
Let procedural systems drive the animation.
Preserve one strong hero frame.
Avoid generic slideshow transitions.
Deliver direction, timeline, implementation, code and QA notes.
```
