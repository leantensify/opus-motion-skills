# Pixel Art — Techniques

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Sprite Run | Animate a short 4–8 frame character cycle across the scene. |
| 02 | Platform Type | Use letters or words as platforms the sprite can traverse. |
| 03 | Coin Spin | Rotate/flip a low-frame-count collectible that doubles as the circle motif. |
| 04 | Score Tick | Increment score or counters in discrete steps. |
| 05 | Tile Reveal | Populate the level by switching tiles from empty to active states. |
| 06 | Start Blink | Blink a ▶ START prompt at a fixed retro cadence. |
| 07 | Jump Arc | Use quantized integer-coordinate parabolic motion. |
| 08 | Screen Shake | Apply a tiny whole-canvas offset for impacts, limited to a few frames. |
| 09 | Palette Swap | Change the entire indexed palette rather than animating individual colors. |
| 10 | Pixel Dissolve | Disperse tiles/pixels from solid forms into the next composition. |

## Combination rule
Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA
- Can the style be recognized with color removed?
- Is motion driven by the style's engine?
- Does at least one technique support the message directly?
