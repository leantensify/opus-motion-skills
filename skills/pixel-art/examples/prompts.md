# Pixel Art — Prompt Examples

## Example 1

```text
Create an 8-second pixel-art product teaser at a true low-resolution canvas. A sprite runs across three feature words as platforms and collects one branded coin.
```

## Example 2

```text
Build a retro game loop where a pickup changes the score into the product's key metric. Use only integer-positioned animation.
```

## Example 3

```text
Transition from pixel art to a hand-drawn sketch by scattering pixel cells into graphite dots and connecting them with strokes.
```

## Reusable brief

```text
Create a [DURATION] Pixel Art motion scene.
Objective: [OBJECTIVE]
Content: [CONTENT]
Required moments: [MOMENTS]
Constraints: [FORMAT / BRAND / AUDIO]
Let sprites on a grid drive the animation.
Preserve one strong hero frame.
Avoid generic slideshow transitions.
Deliver direction, timeline, implementation, code and QA notes.
```
