# Pixel Art — Timing

| # | Pattern | Guidance |
| --- | --- | --- |
| 01 | Animation cadence | Use held frames; avoid smooth 30fps limb interpolation. |
| 02 | Jump | 0.4–0.8s depending on scale; apex should be visually clear. |
| 03 | Pickup | 3–8 frames for flash/spin, then immediate score response. |
| 04 | Scene reveal | 1–2s to establish game rules before fast action. |

## General rules
Establish the system before escalating it. Let one major event dominate each beat. Hold important copy after motion settles. Review once with audio muted.
