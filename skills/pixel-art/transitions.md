# Pixel Art — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Pixels → Pencil Dots | Change square particles into graphite marks. |
| 02 | Tiles → Isometric | Extrude square tiles into cubes. |
| 03 | Sprite → Cursor | Turn player sprite into a pointer for Brutalist Web. |
| 04 | Score → Terminal | Translate HUD score into monospace process output. |
| 05 | Dissolve → Generative | Release pixel particles into a flow field. |
| 06 | Coin → Circle | Scale collectible into a clean geometric disc. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
