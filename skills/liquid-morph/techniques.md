# Liquid Morph — Techniques

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Metaball Orbit | Orbit multiple blobs close enough to merge visually through the goo filter. |
| 02 | Split Drop | Stretch one mass until surface tension breaks it into smaller drops. |
| 03 | Shape Absorb | Let a large blob swallow a smaller icon or label and inherit its state. |
| 04 | Play Morph | Reshape a rounded mass into a triangular play symbol without a cut. |
| 05 | Drip Type | Reveal letters as if pulled downward from a liquid ceiling. |
| 06 | Surface Wobble | Use damped sinusoidal deformation after impact. |
| 07 | Pour Transition | Flow the entire composition toward one edge as if affected by gravity. |
| 08 | Bubble Rise | Release small secondary circles that rise and merge back into the main form. |
| 09 | Liquid Mask | Use the expanding silhouette as a reveal mask for underlying footage/content. |
| 10 | Freeze Frame | Suddenly remove deformation and texture the blob as paper/glass/solid material. |

## Combination rule
Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA
- Can the style be recognized with color removed?
- Is motion driven by the style's engine?
- Does at least one technique support the message directly?
