# Liquid Morph — Prompt Examples

## Example 1

```text
Create a 9-second liquid-morph identity animation. Preserve mass as one blob splits, becomes a play symbol, then reforms into the brand wordmark.
```

## Example 2

```text
Make a fluid transition from a circular logo into a full-frame color field and then into typography. Use continuity, not cuts.
```

## Example 3

```text
Build a seamless 6-second loop with orbiting metaballs that merge into one symbol and separate back to the starting state.
```

## Brief template

```text
Create a [DURATION] Liquid Morph motion sequence.

Objective:
[WHAT THE VIEWER SHOULD UNDERSTAND OR FEEL]

Content:
[WORDS / DATA / PRODUCT / OBJECTS]

Required moments:
- [MOMENT 1]
- [MOMENT 2]

Constraints:
- [FORMAT / BRAND / SAFE AREA / AUDIO]
- Let fluid merging drive the motion.
- Preserve a clear hero frame.
- Avoid generic fade/slide slideshow behavior.

Deliver:
1. motion direction
2. timeline
3. implementation plan
4. code
5. QA notes
```
