# Liquid Morph — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Blob → Paper Disc | Freeze shape and introduce paper grain/shadow. |
| 02 | Blob → Circle | Settle fluid into a perfect geometric ring/disc. |
| 03 | Drip → Sketch | Thin drips into ink/marker strokes. |
| 04 | Pour → Wipe | Use flowing mass to cover frame and reveal next style. |
| 05 | Bubble → Particles | Break droplets into generative points. |
| 06 | Liquid Text → 3D | Solidify thick letterforms into extruded type. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
