# Terminal — Prompt Examples

## Example 1

```text
Create a 10-second terminal motion piece for an AI coding product. Start with one believable command, stream compact logs, show a small diff, then land on tests passing.
```

## Example 2

```text
Build a terminal-to-data transition where ASCII progress bars become real chart bars. Preserve exact geometry across the handoff.
```

## Example 3

```text
Make a 6-second developer-tool teaser using command → output → success. No Matrix rain or fake hacker clutter.
```

## Brief template

```text
Create a [DURATION] Terminal motion sequence.

Objective:
[WHAT THE VIEWER SHOULD UNDERSTAND OR FEEL]

Content:
[WORDS / DATA / PRODUCT / OBJECTS]

Required moments:
- [MOMENT 1]
- [MOMENT 2]

Constraints:
- [FORMAT / BRAND / SAFE AREA / AUDIO]
- Let output streaming drive the motion.
- Preserve a clear hero frame.
- Avoid generic fade/slide slideshow behavior.

Deliver:
1. motion direction
2. timeline
3. implementation plan
4. code
5. QA notes
```
