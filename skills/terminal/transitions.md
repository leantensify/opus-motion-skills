# Terminal — Transition Recipes

A transition should inherit something from the previous shot and hand something useful to the next one.

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | ASCII Bars → Data Bars | Replace text blocks with real chart rectangles at identical positions. |
| 02 | Cursor → Sketch Point | Turn blinking cursor into the first pencil mark. |
| 03 | Log Lines → HUD Readouts | Reposition terminal outputs as floating telemetry. |
| 04 | Progress → Timeline | Stretch the progress bar into a video/data timeline. |
| 05 | Command → Kinetic Phrase | Scale the command's argument into full-screen typography. |
| 06 | Green Text → Generative Nodes | Break terminal glyphs into particle targets. |

## Transition test

A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only "fade to the next scene", look for a stronger transformation.
