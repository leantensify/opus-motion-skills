# Terminal — Shot & Transition Recipes

## 01 · AI coding demo

Prompt typed → model status lines → diff snippet → tests pass → deploy command.

## 02 · Infrastructure opener

Command → connection logs → service statuses → one metric extracted as next-scene chart.

## 03 · Terminal-to-data

ASCII bars fill, then their exact rectangles become a polished chart.

## 04 · Build sequence

Package steps stream in groups; warnings briefly interrupt; final success line becomes hero title.

## 05 · Short social hook

One command, three output bursts, one unexpected result. Keep under about 8 seconds.

## 06 · End card

Use a final command or shell prompt that contains the CTA without fake interactivity.

## Transition checklist

Before using a cut, ask whether an existing object can become the next scene's mask, grid, axis, circle, block, texture, camera target, or first glyph.
