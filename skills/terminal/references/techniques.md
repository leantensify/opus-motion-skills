# Terminal — Signature Techniques

Use these as a vocabulary, not a checklist.

## 01 · Command Trigger

A typed command initiates the entire scene.

**Implementation:** Type fast but legibly; pause briefly before output begins.

## 02 · Streaming Log

Lines arrive in bursts with consistent prefixes and status tokens.

**Implementation:** Batch related lines rather than constant uniform typing.

## 03 · Progress Morph

ASCII progress characters transform into real graphical bars or blocks.

**Implementation:** Match bar count and width so the morph feels continuous.

## 04 · ASCII Banner

Render a short phrase in block characters for a hero beat.

**Implementation:** Keep width within the terminal viewport.

## 05 · Cursor Hold

Use a blinking cursor as intentional tension before a reveal.

**Implementation:** Do not keep it blinking everywhere.

## 06 · Status Ladder

Sequential [pending] → [running] → [ok] rows show progression.

**Implementation:** Change one row at a time to create causal rhythm.

## 07 · Diff Reveal

Show removed/added lines as a compact code or config transformation.

**Implementation:** Use restrained red/green semantics and avoid long code dumps.

## 08 · Spinner-to-Ring

ASCII spinner characters accelerate then become a graphical circle/ring.

**Implementation:** Synchronize shape phase during morph.

## 09 · Prompt Echo

User input reappears transformed as structured output.

**Implementation:** Good for AI or CLI product storytelling.

## 10 · Timer Tick

Use elapsed time or frame count as a pacing device.

**Implementation:** Align significant moments to readable milestones.

## 11 · Pane Split

Divide terminal into two panes for input/output or local/remote states.

**Implementation:** Keep focus on one active pane at a time.

## 12 · Exit Transition

A command such as clear, exit, render, deploy or open triggers the next visual language.

**Implementation:** Use the command semantics as the transition reason.

## Selection rule

For a short scene, 2–4 techniques are usually enough. Simplify when technique count starts competing with the message.
