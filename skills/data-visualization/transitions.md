# Data Visualization — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Bars → Isometric Blocks | Extrude rectangles into modular 3D units. |
| 02 | Points → Particles | Release plotted points into a generative field. |
| 03 | Timeline → Terminal Progress | Quantize the chart timeline into text-mode progress. |
| 04 | Outlier → Circle | Promote a point into a graphic disc used by another style. |
| 05 | Axis → Swiss Grid | Extend chart axes into a full editorial grid. |
| 06 | Line → Sketch | Roughen a line path until it becomes hand drawn. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
