# Data Visualization — Techniques

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Bar Re-rank | Animate categories changing order while preserving object identity. |
| 02 | Count Up | Interpolate meaningful values with restrained formatting. |
| 03 | Scatter Morph | Transition bars or rows into x/y plotted marks. |
| 04 | Outlier Focus | Desaturate context and enlarge/annotate one exceptional point. |
| 05 | Line Draw | Reveal a time series with a moving playhead. |
| 06 | Scrubber | Use a handle that moves through time and updates the entire scene. |
| 07 | Small Multiples | Repeat the same chart structure for multiple segments. |
| 08 | Stack Unstack | Decompose a total into component contributions. |
| 09 | Threshold Cross | Animate a measure crossing a target/reference line. |
| 10 | Annotation Follow | Attach labels that track the datum instead of floating independently. |

## Combination rule
Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA
- Can the style be recognized with color removed?
- Is motion driven by the style's engine?
- Does at least one technique support the message directly?
