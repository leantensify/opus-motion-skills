# Data Visualization — Timing

| # | Pattern | Guidance |
| --- | --- | --- |
| 01 | Chart establish | 0.8–1.5s to show axes/structure before major transformation. |
| 02 | Re-rank | 0.8–1.4s with labels traveling with bars. |
| 03 | Count up | Match numeric interpolation to geometry; avoid numbers finishing early. |
| 04 | Annotation | Delay 150–300ms after the relevant mark settles. |

## General rules
Establish the system before escalating it. Let one major event dominate each beat. Hold important copy after motion settles. Review once with audio muted.
