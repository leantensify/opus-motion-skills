# Data Visualization — Shot & Transition Recipes

## 01 · Metric proof

Headline number → bar comparison → annotation → concise conclusion.

## 02 · Before/after

Show baseline state, animate changed values, reorder only after values settle.

## 03 · Outlier story

Scatter plot establishes distribution → one mark separates → annotation explains why.

## 04 · Time-series explainer

Line draws with playhead; key moments pause for labels; end state becomes final KPI.

## 05 · Data-to-isometric

Bars extrude into blocks while retaining rank/order, then camera shifts into isometric scene.

## 06 · Social stat

Use one chart and one insight only; avoid dashboard density.

## Transition checklist

Before using a cut, ask whether an existing object can become the next scene's mask, grid, axis, circle, block, texture, camera target, or first glyph.
