# Data Visualization — Prompt Examples

## Example 1

```text
Create a 12-second metric story from these values. Use object constancy, a bar re-rank and one annotated outlier. Do not invent data.
```

## Example 2

```text
Animate a time series with a scrubber and two labeled turning points. Preserve scale and make the takeaway readable without audio.
```

## Example 3

```text
Transition a bar chart into an isometric modular world by extruding the existing bars rather than cutting to unrelated 3D objects.
```

## Brief template

```text
Create a [DURATION] Data Visualization motion sequence.

Objective:
[WHAT THE VIEWER SHOULD UNDERSTAND OR FEEL]

Content:
[WORDS / DATA / PRODUCT / OBJECTS]

Required moments:
- [MOMENT 1]
- [MOMENT 2]

Constraints:
- [FORMAT / BRAND / SAFE AREA / AUDIO]
- Let data transitions drive the motion.
- Preserve a clear hero frame.
- Avoid generic fade/slide slideshow behavior.

Deliver:
1. motion direction
2. timeline
3. implementation plan
4. code
5. QA notes
```
