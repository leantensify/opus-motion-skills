# Brutalist Web — Signature Techniques

Use these as a vocabulary, not a checklist. Select the smallest combination that produces a distinct scene.

## 01 · Cursor Causality

Every click changes layout, state, color, route or content.

**Implementation:** Never animate a cursor wandering without purpose.

## 02 · Visited Link

A clicked blue link becomes purple and triggers the next composition.

**Implementation:** Use native-looking underline and selection states.

## 03 · Alert Interrupt

A modal/alert abruptly interrupts the frame, then becomes a transition surface.

**Implementation:** Keep copy short and intentionally system-like.

## 04 · Marquee Drive

Scrolling text supplies continuous lateral motion behind hard-cut foreground states.

**Implementation:** Use one or two marquee bands, not an unreadable wall.

## 05 · Border Swallow

A thick bordered box expands until its border becomes the frame edge.

**Implementation:** Animate dimensions in discrete-feeling steps.

## 06 · Selection Highlight

Text selection becomes a color block that wipes or reveals the next scene.

**Implementation:** Match the highlight rectangle to actual text metrics.

## 07 · Window Resize

The page snaps between desktop-like and tiny-window layouts.

**Implementation:** Animate viewport container dimensions with minimal easing.

## 08 · Hit Counter

A numeric counter updates on interactions and becomes a compositional motif.

**Implementation:** Use monospaced digits and abrupt increments.

## 09 · Default Button Press

A gray system-style button visibly depresses then changes page state.

**Implementation:** Use transform/box-shadow changes only; keep it convincingly primitive.

## 10 · DOM Reorder

Sections jump or reinsert themselves as if JavaScript changed document order.

**Implementation:** Prefer instant reflow plus a short emphasis flash.

## 11 · Error-State Cut

A broken state or 404 becomes the bridge to a new visual section.

**Implementation:** Use sparingly so it reads as intentional narrative.

## 12 · Scroll Jump

Scroll position jumps to anchors rather than easing smoothly.

**Implementation:** Pair with hash-like labels or section IDs.

## Selection rule

For a short scene, 2–4 techniques are usually enough. If more than five are active simultaneously, simplify unless the deliberate goal is controlled overload.
