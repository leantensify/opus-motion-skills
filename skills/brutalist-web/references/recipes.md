# Brutalist Web — Shot & Transition Recipes

## 01 · Devtool hook

Raw H1 appears → cursor clicks command/link → page explodes into bordered modules → alert reveals product name.

## 02 · Anti-ad ad

Start with intentionally ugly page; each click progressively reveals the actual message without becoming polished.

## 03 · Feature demo parody

Represent features as links/buttons; user 'navigates' through them through abrupt page states.

## 04 · Transition to blueprint

Expand a black border to frame; thin it to 1px; recolor background into blueprint sheet.

## 05 · Social loop

Marquee loops continuously while cursor cycles through 3 state changes that reset seamlessly.

## 06 · End card

A final system dialog asks a concise CTA; one button is highlighted/pressed.

## Transition checklist

Before using a cut, ask whether an existing object can become:
- the next scene's mask
- a grid/rule/axis
- a circle/ring/portal
- a block/bar/module
- a texture or background field
- the camera target
- the first letter or shape of the next composition

A cut is appropriate when discontinuity is the point. Otherwise prefer a motivated handoff.
