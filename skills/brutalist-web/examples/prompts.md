# Brutalist Web — Prompt Examples

## Example 1

```text
Create a 9-second brutalist-web launch clip for a developer tool. Use default HTML aesthetics, blue links, a gray button, cursor-driven state changes and hard cuts. No glassmorphism.
```

## Example 2

```text
Build a raw browser-native sequence where clicking three links reveals three product benefits. The cursor must cause every major transition.
```

## Example 3

```text
Make an intentionally unpolished 6-second social loop using marquee text, a hit counter and one alert box. Keep it readable.
```

## Brief template

```text
Create a [DURATION] Brutalist Web motion sequence.

Objective:
[WHAT THE VIEWER SHOULD UNDERSTAND OR FEEL]

Content:
[WORDS / DATA / PRODUCT / OBJECTS]

Required moments:
- [MOMENT 1]
- [MOMENT 2]

Constraints:
- [FORMAT / BRAND / SAFE AREA / AUDIO]
- Let cursor + hard cuts drive the motion.
- Preserve a clear hero frame.
- Avoid generic fade/slide slideshow behavior.

Deliver:
1. motion direction
2. timeline
3. implementation plan
4. code
5. QA notes
```
