# Brutalist Web — Techniques

These are reusable building blocks, not mandatory effects. Pick the smallest set that makes the brief clearer.

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Raw Page Load | Reveal plain document structure instantly: heading, links, borders, button, status text. |
| 02 | Cursor Click Chain | Use the pointer as the causal actor for successive scene changes. |
| 03 | Visited Link | Change link color/state after interaction to make the UI feel real. |
| 04 | Alert Pop | Introduce a browser-like alert or blocking box for comic emphasis. |
| 05 | Marquee Track | Run intentionally crude repeated text in a horizontal marquee. |
| 06 | Hard State Swap | Replace panels with zero interpolation; the edit is the aesthetic. |
| 07 | Hit Counter | Use mechanical counters, timestamps, or page-state numbers as motion punctuation. |
| 08 | Selection Highlight | Drag-select text to reveal or emphasize content. |
| 09 | Border Swallow | Grow a heavy border box until it consumes the frame. |
| 10 | Broken Layout Nudge | Introduce controlled awkward offsets while keeping readability intentional. |

## Combination rule

Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA

- Can the scene still be identified as Brutalist Web with the color removed?
- Is the motion driven by the style's engine rather than generic transforms?
- Does at least one technique directly support the message?
