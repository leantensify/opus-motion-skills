# Brutalist Web — Transition Recipes

A transition should inherit something from the previous shot and hand something useful to the next one.

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Border → Blueprint | Thin a thick black border into a technical drafting line while recoloring the field. |
| 02 | Button → Play Control | Carry the same native-looking button into another UI-based style. |
| 03 | Selection → Mask | Use selected text highlight as a rectangular wipe. |
| 04 | Alert → Terminal | Collapse alert copy into terminal output. |
| 05 | Marquee → Type Wall | Refine raw marquee into polished repeated kinetic type. |
| 06 | Cursor → Reticle | Transform pointer coordinates into a tracking reticle. |

## Transition test

A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only "fade to the next scene", look for a stronger transformation.
