# Isometric — Techniques

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Tile Wave | Populate the floor grid in a diagonal or radial wave. |
| 02 | Voxel Letter Build | Assemble typography cube-by-cube while preserving readable silhouette. |
| 03 | Module Drop | Drop blocks onto exact grid cells with controlled bounce. |
| 04 | Cylinder Rise | Extrude a circular base upward to establish depth. |
| 05 | Camera Pan | Move laterally across a miniature system without violating projection. |
| 06 | Layer Stack | Build vertical layers representing system levels or states. |
| 07 | Path Pulse | Send a light/marker along grid-connected routes. |
| 08 | Press Pad | Depress a platform or button into the isometric floor. |
| 09 | Exploded Module | Lift related components apart along parallel isometric axes. |
| 10 | Sequence Light | Illuminate modules in order to show process flow. |

## Combination rule
Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA
- Can the style be recognized with color removed?
- Is motion driven by the style's engine?
- Does at least one technique support the message directly?
