# Isometric — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Block → Liquid | Melt the top surface of a solid module into a blob. |
| 02 | Tiles → Pixel Grid | Flatten depth until tiles become square pixels. |
| 03 | Extrusion → Cinematic 3D | Increase perspective/depth and transition to full 3D camera. |
| 04 | Path → Data Line | Flatten a route into a chart line. |
| 05 | Cylinder → Circle | Top-down camera resolves cylinder into a flat disc. |
| 06 | Grid → HUD | Overlay coordinates and transform the floor into a scan grid. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
