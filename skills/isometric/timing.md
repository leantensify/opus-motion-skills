# Isometric — Timing

| # | Pattern | Guidance |
| --- | --- | --- |
| 01 | Assembly | Use 50–120ms stagger for repeated blocks. |
| 02 | Camera pan | 1.5–3.0s for meaningful traversal; keep point of interest stable. |
| 03 | Bounce | One small overshoot only; avoid toy-like perpetual springing. |
| 04 | Process pulse | Travel speed should make route order easy to follow. |

## General rules
Establish the system before escalating it. Let one major event dominate each beat. Hold important copy after motion settles. Review once with audio muted.
