# Isometric — Prompt Examples

```text
Create a 12-second isometric workflow scene for a SaaS product. Build the world from tiles, show a token moving through four stages, and keep projection consistent.
```

## Example 2

```text
Turn these ranked chart bars into an isometric modular city without losing their relative order.
```

## Example 3

```text
Build an 8-second system overview with tile waves, modular assembly, one path pulse and a clear hero node.
```
