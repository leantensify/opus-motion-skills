# Isometric — Shot & Transition Recipes

## 01 · System overview

Tile wave → key modules assemble → paths pulse → one node becomes hero.

## 02 · Workflow explainer

Each stage occupies a zone; a token travels along a lit path from stage to stage.

## 03 · Data-to-world

Chart bars skew or extrude into blocks, then background grid rotates into isometric projection.

## 04 · Product ecosystem

Core module arrives first; supporting modules snap around it by category.

## 05 · Manufacturing line

Objects move tile-to-tile through process stations; use height and state changes to show transformation.

## 06 · Isometric-to-liquid

A cylinder top or circular tile softens and melts into the next scene.

## Transition checklist

Before using a cut, ask whether an existing object can become the next scene's mask, grid, axis, circle, block, texture, camera target, or first glyph.
