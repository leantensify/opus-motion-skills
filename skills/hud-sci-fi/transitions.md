# HUD / Sci-Fi — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Grid → Particles | Dissolve scan grid intersections into generative points. |
| 02 | Reticle → Circle | Strip away telemetry until only the core ring remains. |
| 03 | Readouts → Terminal | Collapse floating labels into a mono text stream. |
| 04 | Radar → Retro Orbit | Simplify radar arcs into vintage orbit diagram. |
| 05 | Tracking Box → Swiss Module | Square the HUD frame into editorial grid geometry. |
| 06 | Scan → Blueprint | Freeze scan paths as measurement lines. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
