# HUD / Sci-Fi — Prompt Examples

## Example 1

```text
Create a 10-second HUD motion scene for an AI vision product. Scan one object, lock a reticle, reveal a compact ID/confidence readout, then trigger an action.
```

## Example 2

```text
Build a functional sci-fi diagnostic interface. Every micro-label must correspond to a visible object or measurement; no decorative telemetry.
```

## Example 3

```text
Transition a HUD grid into generative particles by detaching real grid intersections and letting them enter a flow field.
```

## Reusable brief

```text
Create a [DURATION] HUD / Sci-Fi motion scene.
Objective: [OBJECTIVE]
Content: [CONTENT]
Required moments: [MOMENTS]
Constraints: [FORMAT / BRAND / AUDIO]
Let tracking + micro-data drive the animation.
Preserve one strong hero frame.
Avoid generic slideshow transitions.
Deliver direction, timeline, implementation, code and QA notes.
```
