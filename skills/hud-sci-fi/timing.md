# HUD / Sci-Fi — Timing

| # | Pattern | Guidance |
| --- | --- | --- |
| 01 | Acquisition | 0.5–1.2s from search to lock. |
| 02 | Telemetry | Numbers can update continuously, but major values should stabilize for reading. |
| 03 | Scan | 0.8–1.8s per sweep; too fast reads as decoration. |
| 04 | Status payoff | Hold LOCKED / VERIFIED / ENGAGED for 0.5–1.0s. |

## General rules
Establish the system before escalating it. Let one major event dominate each beat. Hold important copy after motion settles. Review once with audio muted.
