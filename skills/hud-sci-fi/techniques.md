# HUD / Sci-Fi — Techniques

| # | Technique | How to use it |
| --- | --- | --- |
| 01 | Reticle Lock | Animate brackets/reticle inward until target confirmation. |
| 02 | Object Track | Attach labels and bounding markers to moving scene objects. |
| 03 | Scan Sweep | Move a line or radial sweep that reveals measured information. |
| 04 | Radar Arc | Rotate sectors/arcs around a meaningful center. |
| 05 | Telemetry Tick | Update small numeric readouts at different but restrained cadences. |
| 06 | Target ID | Assign OBJ_01-style identifiers and keep them spatially anchored. |
| 07 | Engage Toggle | Use a binary control to trigger a visible system response. |
| 08 | Range Ring | Expand concentric circles to imply sensing or acquisition. |
| 09 | Vector Trace | Draw motion vectors from target position/history. |
| 10 | Lock Confirmation | Use one concise status change — SEARCHING → LOCKED — as payoff. |

## Combination rule
Use 2–4 primary techniques in a short scene. Repetition should create a system; adding every technique creates noise.

## QA
- Can the style be recognized with color removed?
- Is motion driven by the style's engine?
- Does at least one technique support the message directly?
