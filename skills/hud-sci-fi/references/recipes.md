# HUD / Sci-Fi — Shot & Transition Recipes

## 01 · AI vision scene

Object appears → scan sweep → brackets lock → ID/confidence appears → one action triggers.

## 02 · Robotics diagnostic

Robot/component tracked → three measurements update → warning/OK state resolves.

## 03 · 3D-to-HUD

Fly through 3D ring → stop camera at center → ring gains ticks/brackets and becomes reticle.

## 04 · HUD-to-generative

Scan grid freezes → intersections detach → particles flow into next system.

## 05 · Feature explainer

One tracked object per beat; reuse same HUD framework instead of changing UI every shot.

## 06 · End card

Reticle releases and UI simplifies to one centered status plus brand/CTA.

## Handoff rule

Reuse an existing camera target, ring, grid, field, point set or geometry as the first element of the next scene whenever possible.
