# Paper Cut / Collage — Prompt Examples

## Example 1

```text
Create a 10-second paper-collage motion piece for a fashion campaign. Use layered photo crops, tape, torn edges and stepped stop-motion timing. Keep the headline readable.
```

## Example 2

```text
Build an editorial quote animation from cut-paper typography and one stamped accent. Avoid smooth UI easing.
```

## Example 3

```text
Transition from a tactile paper collage into pixel art by quantizing the paper layers into square cells.
```

## Reusable brief

```text
Create a [DURATION] Paper Cut / Collage motion scene.
Objective: [OBJECTIVE]
Content: [CONTENT]
Required moments: [MOMENTS]
Constraints: [FORMAT / BRAND / AUDIO]
Let physical layers drive the animation.
Preserve one strong hero frame.
Avoid generic slideshow transitions.
Deliver direction, timeline, implementation, code and QA notes.
```
