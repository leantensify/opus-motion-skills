# Paper Cut / Collage — Transition Recipes

| # | Recipe | Mechanism |
| --- | --- | --- |
| 01 | Paper → Pixels | Reduce collage texture into blocky square samples. |
| 02 | Tape → Swiss Rule | Stretch tape into a clean geometric rule. |
| 03 | Cut Edge → Sketch Line | Convert torn contour into pencil stroke. |
| 04 | Disc → Liquid | Remove paper texture and let the disc soften into fluid. |
| 05 | Photo → Cinematic Frame | Scale a pinned image until it becomes full-screen content. |
| 06 | Stamp → Brutalist Alert | Turn stamped label into a raw bordered UI box. |

## Transition test
A good hand-off can be described as: **this existing object becomes that next object**. If the explanation is only “fade to the next scene”, find a stronger transformation.
