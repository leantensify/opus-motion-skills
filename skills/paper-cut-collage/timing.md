# Paper Cut / Collage — Timing

| # | Pattern | Guidance |
| --- | --- | --- |
| 01 | Stop motion | Animate key movement on 2s or 3s (12–15fps equivalent at 30fps). |
| 02 | Placement | 150–350ms per element, followed by tiny 1–2 frame settle. |
| 03 | Layer peel | 0.8–1.4s to make material behavior readable. |
| 04 | Dense collage | Build in clusters rather than one element per beat for too long. |

## General rules
Establish the system before escalating it. Let one major event dominate each beat. Hold important copy after motion settles. Review once with audio muted.
