# CLAUDE.md

This repository is a motion-design skill library.

When generating or editing skills:
- treat motion as a design system, not a collection of effects
- define a clear motion engine
- prefer motivated transformations over generic fades
- preserve readability
- make timing explicit
- keep implementation advice practical
- do not claim a technique requires a specific model
- do not add copyrighted third-party assets to the repository

When using multiple styles, consult `skills/motion-director/SKILL.md` first.
