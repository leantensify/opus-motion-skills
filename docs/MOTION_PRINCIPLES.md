# Shared Motion Principles

These principles apply across all styles.

## Motion has a cause

Every major movement should have a reason:
- a word hits
- a grid reflows
- a command returns output
- a scan detects something
- a camera approaches a target
- a physical layer is placed
- a system changes state

Avoid motion whose only explanation is “to make the frame more dynamic.”

## Preserve continuity

When possible, carry an existing visual element into the next state. Continuity reduces cognitive load and makes ambitious transitions feel inevitable.

## Design the pause

A motion piece is a sequence of still compositions connected through time. Check hero frames independently.

## Protect reading time

Fast animation is not an excuse for unreadable copy. The viewer needs enough stable time to parse the important message.

## Contrast creates rhythm

Across a sequence, alternate one or two macro qualities:
- fast / slow
- dense / sparse
- rigid / organic
- flat / deep
- dark / light

Do not change every property at once.

## Determinism matters

For coded motion, the same time value should produce the same frame whenever possible. Seed randomness and avoid simulation drift in render-critical systems.
